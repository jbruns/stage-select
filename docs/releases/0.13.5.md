# Stage Select 0.13.5

This release finishes what 0.13.4 began for permission changes on your host. A change of permissions or owner no longer
makes a source set stale when no byte changed. Your next audit reads just those files again.

## Upgrading

0.13.5 opens your 0.13.4 store and updates it in place. The update can't be undone: an earlier release won't open the
store afterwards. Your store is backed up first, as before every update.

- A source set record can now carry `unconfirmed`: how many files its latest check found with only their change time
  moved. A check's results carry it too.

## Changes you'll notice

- **A permission change alone no longer makes a source set stale.** A file whose size and modification time are as
  your last audit recorded them, but whose permissions or owner changed, is unconfirmed rather than changed. The source
  set says "N files' permissions or owner changed; their size and time are the same. Your next audit re-reads just
  these." Nothing starts by itself.
- **Your next incremental audit reads only those files.** If their bytes are the same, it records their new stamps and
  the source set is fresh again. If they differ, it records the change.
- **Plans read such files again instead of refusing them.** A repair plan, or a build plan that places games with
  single copy, reads an unconfirmed file again. If its bytes are what your audit read, the plan goes ahead without a new
  audit. If they differ, the plan leaves the file out and says so, and the source set reads stale until you audit it.
