# Stage Select 0.13.1

This release follows your first run of 0.13.0: it makes first run easier, lets Stage Select change your source sets
per source set, and adds what library folders and source sets were missing.

## Upgrading

Upgrade in place: 0.13.1 opens your 0.13.0 store and adds to it. The API and the machine-readable formats only gain
fields and routes; nothing is deprecated or removed.

## Changes you'll notice

- **Stage Select may change this source set.** Each source set now has one switch, on by default when you register
  it, that lets repairs change it and lets single copy place its games into library folders. It replaces the root's
  "Paths repairs may write to" list in the workbench. A source set you registered in 0.13.0 keeps what its root's list
  says: if single copy copied every game instead of placing it, switch this on for the source set and plan the build
  again. Switching it off voids the approved plans that would write to it, and says which.
- **Source sets never nest.** Registering a source set whose folder is inside another source set's folder, or holds
  one, is refused, and so is moving a root so that two would nest.

## New

- **A folder browser** beside every path: a root's, a source set's and a library folder's. A root's starts at `/`.
- **Create a missing folder** when you register a root ("Create this folder") or a source set ("Create an empty
  source set", for a new set that ingest will fill). Nothing is created unless you ask, never outside the root, and a
  refused registration removes what it made.
- **Remove chosen games from a library folder:** send a placed game back to its source set, set it aside, or delete
  it. Later builds leave it out until you restore it from the folder's overview.
- **Delete a library folder** in one plan: games placed under single copy go back to their source set, every other
  file is deleted, the folder is removed if nothing else is left in it, and it is unregistered.
- **Change a source set's DAT** in place, from its overview's actions. It keeps its history, and earlier audits keep
  the DAT revision they used; audit it again to use the new DAT.

## Fixes

- Each choice's note sits under its own choice, rather than wrapping under its name.
- First run shows each step's status at the top right of its box.
