# Stage Select 0.14.2

This release fixes two things that kept library folders from settling: a choice saved for one system made every
library folder that uses the profile stale, and a game the clone list groups by disc couldn't be resolved at all.

## Upgrading

0.14.2 opens your 0.14.1 store as it is: there's no update to the store, and you can go back to 0.14.1. A library
folder that reads stale only because you saved a choice or settings for another system reads fresh once you start
0.14.2, with no build needed.

Nothing in the API changes. A library folder's `stale` reason `profile_saved` now appears only when the newer version
could change its selection.

## Fixes

- **Saving a choice for one system no longer makes every library folder stale.** A library folder is stale after you
  save its selection profile only when the save could change what it builds: the profile's general settings, or its
  settings or choices for the folder's system. Saving a choice or settings for another system leaves it as it was,
  and so does saving a change you then undo. The profile's library folders tab no longer tells you to build a folder
  just because a newer version exists; the folder says whether that version changes its games.
- **A game the clone list groups by disc can be resolved.** Some clone lists group a multi-disc game's discs by their
  content, so one group holds one region's disc 1 and another region's disc 2. Such a group read unresolved whatever
  you chose, and blocked your build plan. Now each release you choose there needs only its own discs, so your choice,
  or the one made for you, resolves it.

## Known limits

- The two discs of a game resolved this way are laid out as two games, each with one disc, and with no `.m3u`.
