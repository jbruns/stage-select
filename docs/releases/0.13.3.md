# Stage Select 0.13.3

This release follows more of your first run: plans show how far along they are and are made much faster, a library
folder is incomplete only for gaps it can fill, and an audit spots a stray duplicate of a game you already have.

## Upgrading

0.13.3 opens your 0.13.2 store and updates it in place; the update only adds. Nothing you send changes.

- An audit entry can now carry `complete_in`, naming the file that already makes its game complete. Entries from
  earlier audits have none until you audit again.
- A build plan item and a library folder's incomplete item can now carry `available`, naming another release in the
  same game group that your source set has. An approved build plan made before 0.13.3 whose game has such a release
  asks you to plan again.
- Plans can be made in the background: `POST /api/source-sets/{name}/repair-plannings` and
  `POST /api/libraries/{id}/plannings` answer at once, and `GET /api/plannings/{id}` reports progress and the plan.
  The existing calls that wait for the plan are unchanged.

## Changes you'll notice

- **Plans show a percentage.** While a repair or build plan is being made, its meter says which step it's on and how
  far through it is, rather than only how long it's taken.
- **Repair plans are made much faster.** A repair plan for a large source set took more than ten seconds and now takes
  under a second.
- **Games your source set lacks don't make a library folder incomplete.** When your selection chose a game your source
  set has no file for, the folder lists it under "Not in your source set", and names another release in the same game
  group if your source set has one. It doesn't place that release for you. Any other gap still makes the folder
  incomplete.
- **A stray duplicate counts for one game, and a repair sets it aside.** A ZIP or folder named for no game, such as a
  copy under an older DAT name, now counts towards the one game its checksums single out, rather than towards every
  game sharing one of its tracks. Those other games no longer read incomplete because of it. Its entries say
  "Duplicate" and name the file that already makes the game complete, and a repair sets it aside by default.
- **Games chosen through compilations show in their own game groups.** A selection no longer gathers games such as
  Super Mario Bros. into one group of compilation winners; each shows in the game group it belongs to.

## Fixes

- After a build places games with single copy, or after you return them, your source set no longer reads stale for
  every file that moved.
