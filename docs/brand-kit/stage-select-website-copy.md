# Stage Select website copy

Identity v2.0 · 15 November 2026

This copy is for a future website and for anything else that introduces Stage Select to someone who doesn't run it
yet. **None of it goes into the product**: not the workbench, not CLI help or output, not error messages. The
product's own voice is in the Voice section of `stage-select-style-guide.md`.

## Lines

- Descriptor: **ROM organizer**. Longer, where the context needs it: **ROM curation utility**.
- Signature: **Well kept. Ready to play.**
- Headline: **Great collections. Ready to play.**
- Supporting line: **Preserve source sets. Build the library you want to play.**
- Rhythm: **Keep. Select. Play.**
- Short description: **Stage Select organizes and verifies ROM collections across video game systems, preserving
  source sets and deriving carefully selected libraries for play.**

## Three principles

1. **Keep.** Preserve source files, variants, provenance and integrity records.
2. **Select.** Choose releases through explicit region, language and revision rules, with an inspectable reason for
   every decision.
3. **Play.** Derive a useful library with the files and dependencies each selected release needs.

Personality: confident in presentation, meticulous in operation, enthusiastic about games and respectful of the
collection.

## Website voice

The website can be enthusiastic where the product is exact. It still makes no claim the product can't keep; the
style guide's "Claims the brand must not make" applies here too.

- Avoid collection-size bragging and completion pressure. A small, well-chosen library is complete.
- Say what Stage Select does to files plainly: it reads source sets, and changes them only through a plan the
  reader approves.
- Arcade, console, handheld and other systems are all in scope, including MAME collections. Don't present MAME as
  a separate product.

## Website graphics

These treatments belong to the website. The workbench uses none of them.

- **Bands.** Alternating horizontal bands of Night `#0B1026` and `#0E1430`, 30 px each, behind the lockup or a
  headline.
- **Selector rhythm.** Three numbered cells, **01 Keep / 02 Select / 03 Play**, the middle one in Chosen yellow
  inside Sky brackets. It is the emblem's centre row, enlarged.
- **Display type.** Chakra Petch 700, uppercase, for short headlines. Keep it out of paragraphs.
- Use one treatment per composition. Keep the artwork flat: no glow, gradient, extrusion or texture.
